# Arisca Light Studio ✦ Ahmedabad

> **"Light that *lives* in your room."**  
> Luxury architectural lighting, designer chandeliers, pendants, and glare-free COB downlights.

Located at **Jagatpur Road, Ahmedabad**, Arisca Light Studio bridges technical architectural illumination with high-end interior aesthetics. This web application offers clients, interior designers, and architects a tactile digital showroom experience.

### ✨ Key Features
- **"Lights On" Interactive Previews:** Toggle between studio catalog photography and realistic warm-lit room environments.
- **Engineered Room Lux Calculator:** Real-time wattage, lumen, and fixture count estimations tailored to ceiling heights and room presets.
- **Architectural Downlights Catalog:** Deep-recessed UGR < 19 anti-glare COB fixtures, surface cylinders, and trimless profiles with tiered trade pricing.
- **Client Project Diaries:** Real installations from luxury villas, penthouses, and residences across Ahmedabad.
- **Mobile-First Luxury Experience:** 2-column smartphone product grids, slide-over navigation drawer, and seamless WhatsApp inquiry checkout.
- **Architect & Designer Trade Portal:** Sample loan requests, photometric dialux support, and priority project fulfillment.

### 🛠️ Built With
- **Framework:** React 18 + Vite
- **Styling:** Custom CSS Architecture & Micro-Animations
- **Icons:** Lucide React
- **SEO & Performance:** JSON-LD Schema markup, WebP optical assets, WCAG AA color contrast
